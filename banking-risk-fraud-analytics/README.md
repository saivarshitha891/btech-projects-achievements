# 🏦 Banking Analytics with SQL: Fraud & Risk Detection

## 📌 Overview
This project analyzes 10,000 synthetic banking transactions using SQL to identify fraud, assess credit risk, and segment customers. It's designed to showcase SQL proficiency for job applications in data or banking analytics.

## 📊 Modules
- Data Cleaning
- Fraud Detection
- Customer Segmentation
- Credit Risk Scoring (Simulated)
- Compliance Monitoring

## 📁 Dataset
- synthetic_transactions.csv
- Generated with Python using randomized logic for fields like transaction type, amount, and fraud status.

## 🛠️ Technologies
- PostgreSQL / BigQuery
- SQL
- GitHub

## ✅ Results
- ~2% fraud rate detected
- High-value transactions identified over $10,000
- Customers segmented into 3 activity levels
- Simulated credit risk assigned based on transaction volume

## 🧠 Skills Demonstrated
- Advanced SQL (aggregations, subqueries, CASE, joins)
- Data cleaning and anomaly detection
- Practical banking domain application

## 📎 How to Run
1. Load the `synthetic_transactions.csv` file into your SQL environment.
2. Run the SQL scripts in the `sql_queries/` folder.
